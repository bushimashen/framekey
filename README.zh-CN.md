# FrameKey · 视频抠背景 / 逐帧播放器

> 把一段视频拆成帧，抠掉背景，再导出成透明 PNG、精灵图或带 alpha 的 WebM —— 全部在浏览器里完成，视频不上传。

[English](README.md) | **简体中文**

## 它解决什么问题

做 UI 动效、角色动画、表情包素材时，经常拿到一段**绿幕或纯色背景的视频**，需要变成：
一帧帧透明 PNG、一张精灵图 + 坐标 JSON、或者一段可以直接叠在网页上的透明视频。
在线工具大多要求上传视频、注册账号、加水印；而逐帧抠图这种活又必须能一帧一帧看效果。

FrameKey 把这些放进一个 HTML 文件：拖进视频 → 抽帧 → 吸管点一下背景色 → 应用到全部帧 → 导出。

## 功能

| 步骤 | 能力 |
|---|---|
| 1 上传 | 点击 / 拖拽 / 粘贴导入视频；自动读取时长、分辨率、帧率 |
| 2 抽帧 | 目标帧率可调（内置「估计真实帧率」），画质 `480p / 720p / 1080p` 三档；抽完在缩略图条上预览，点任意帧跳转 |
| 3 去背景 | **吸管**点选背景色或 **自动**从当前帧边缘采样；容差、边缘羽化、去溢色、杂点清理四项参数，拖动即时预览 |
| 4 播放 / 导出 | 空格播放、`←` `→` 逐帧、进度条拖拽；导出当前帧 PNG / 全部帧 ZIP / 精灵图 + JSON / 透明背景 WebM |

- 参数全部实时预览，不必每改一次都等一整轮
- 抽帧结果进内存缓存，回看已抠过的帧是瞬时的
- 导出文件名带时间戳，重复导出不覆盖

## 用法

下载 `index.html`，双击用浏览器打开即可。不需要安装、不需要构建、不需要联网。

> 部分浏览器在 `file://` 下限制 `MediaRecorder` / `crypto.subtle`。若「录制 WebM」不可用，用本地服务方式打开：
>
> ```bash
> python -m http.server 8000
> # 打开 http://localhost:8000
> ```

## 实现要点

- **抠像用 YCbCr 色度距离，不是 RGB 硬比较。** 先把背景色和像素都转到 YCbCr，用 Cb/Cr 的平方距离判定「像不像背景」；亮度 Y 权重降低，所以光照不均的绿幕也能吃掉。
- **软边缘。** 距离落在 `[T, T+F]` 之间时按比例给出 0~1 的 alpha，避免锯齿；`F` 取容差的 15%（最小 2），跟容差联动。
- **去溢色 / 羽化 / 杂点清理都是逐像素扫描的一维数组运算**，复用预分配的 `Float32Array`，不产生 GC 压力，1080p 帧也能连续拖动参数。
- **杂点清理是 3×3 多数派投票**：只有和邻居多数派不一致的像素才被抹平，所以能清掉孤立噪点和空洞，又不会误伤大片半透明区域。
- **ZIP 和 WebM 都是手写的封装器。** `buildZip` 自己算 CRC32、写本地文件头与中央目录；`buildAlphaWebm` 自己拼 EBML/MKV 元素（`mkvEl` / `vint` / `uintBytes` / `f64Bytes`）来封装 VP9，从而输出真正的透明视频。整个文件没有一个外部依赖。
- 帧数据按需解码 + `prefetch` 预取下一帧，滚时间轴不会卡住主线程。
